# Mini Ecommerce Frontend Website

## Overview

A responsive mini e-commerce frontend application developed with modern UI design and interactive shopping functionality. The project simulates an ecommerce browsing experience with product filtering, sorting, and shopping cart management.

## Features

* Responsive ecommerce UI
* Product filtering and sorting
* Shopping cart functionality
* Dynamic cart updates
* Category navigation
* Interactive product cards
* LocalStorage cart management
* Modern responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
